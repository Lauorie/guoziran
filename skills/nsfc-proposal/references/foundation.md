# 研究基础与工作条件的写法

两份文件一起写：`extraTex/3.1.研究基础.tex`（含研究风险的应对措施）、`extraTex/3.2.工作条件.tex`。本章回答评审的三个问题：你做过吗？你做得成吗？出了问题怎么兜底？

## 写什么

| 章节 | 必写 | 不写 |
|---|---|---|
| 研究基础 | 申请人提供的论文、数据、平台、预实验；缺失项的占位；可行性；研究风险与应对 | 申请人没有提供的论文、数据或预实验结果 |
| 工作条件 | 申请人提供的平台与设备；尚缺的条件与解决途径 | 申请人没有提供的平台或设备 |

材料来自科学论证的 `feasibility`、`constraints`、`risks` 与申请人材料（`T/shared/materials/`）。`feasibility` 中 `source: missing` 的条目，已列在 `section_plan.yaml` 本章的 `placeholders` 中，正文逐字照抄这些占位。

## 研究基础

### 研究积累与阶段性成果

- 围绕研究内容的各项任务，写申请人做过什么、掌握什么、已有什么平台。
- 阶段性成果只写可核实的内容：论文、专利、数据、原型、预实验现象。数字取自申请人材料。
- 申请人已发表的论文，按 `bib_resolve.py` 入账的 bibkey 引用；申请人材料中写明的其他成果照原样写。
- 材料中没有的细节写占位，不编造。不写看起来像真的期刊名、影响因子、专利号、样本量。

例：

- 好：本课题组已完成预实验【待补充：预实验的样本量与主要结果】。
- 差：本课题组已在 XXX 期刊发表论文 X 篇。

### 可行性

从理论、技术、团队、条件四方面各写一到三个支撑点，并与研究内容逐条对齐：写作要点「研究任务」中的每个任务，都要说明为什么做得成。某方面没有材料时写占位，不凑理由。

### 研究风险的应对措施

在研究基础中单列。至少 `chapter_checks.min_risks` 条（默认 3 条），技术、进度、资源三类各至少一条，取自 `risks`。每条写：

- 风险描述；
- 早期信号：什么现象或阈值出现时说明风险正在发生；
- 预案或替代路线：含降级目标和降级后仍能交付什么。

例：

- 风险：样本入组慢于计划。
- 早期信号：前 3 个月入组数低于预期的一半。
- 预案：启用申请人已联系的第二家合作单位【待补充：合作单位名称与协议状态】；仍不足时，以现有样本检验主要假设，次要分析降为探索性分析。

即使申请人认为风险较低，三类也各写一条「低风险 + 监测信号 + 预案」。风险条目用 `\subsubsubsection{风险一：……}` 或「风险一」「风险1」开头，便于检查脚本计数。

## 工作条件

- **已具备的条件**：逐条列出平台、数据、样本、算力、团队分工、合规路径（伦理审批的机构与周期），注明「已具备」「可访问」「已获取」「审批中」等状态。只写申请人提供的条件。
- **尚缺的条件与解决途径**：逐条写缺什么、影响哪项研究内容、解决途径（采购、合作、替代数据源、实验降级）、时间表与责任人。申请人没有提供时间表或责任人时写占位。

## 一致性

- 工作条件逐条支撑研究内容的关键任务：列出每个任务，确认工作条件中有对应的平台、数据或样本。
- 风险预案与年度计划兼容：每年的里程碑遇到风险时，有可执行的降级方案。
- 发现对不上的地方，写占位，列入占位清单。

## 写完自查

- 研究基础覆盖每个任务的可行性。
- 没有申请人未提供的论文、数据、平台或设备。
- 风险至少三条，三类齐全，每条有早期信号和预案。
- 工作条件分「已具备」与「尚缺」两部分。
- 占位写法为 `【待补充：……】`，全部列入 `assumptions.md` 的「## 占位清单」。

确定性部分由脚本检查：`chapter_check.py --section 研究基础 --section 工作条件`（风险条数、应对措施、已具备与尚缺、非标准占位、内部编号、绝对化短语）。
