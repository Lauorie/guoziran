# 篇幅对齐

把篇幅从感觉变成可复检的数字：先量，再改，再量。用于「篇幅对齐」任务，也用于收尾时页数或字数超出预算的情形。

## 预算

- 预算唯一来源是 `config.yaml` 的 `length_standard`：各章的字数区间（`files`）、合计区间（`overall`）、页数（建议不超过 `pages.max`，原则上不超过 `pages.hard_max`）。
- 页数是硬约束，以编译出的 PDF 为准。字数是代理指标，用于改写后的复检。`cjk_chars` 只统计汉字，英文、数字和标点会被低估。
- 预算是示例口径。申请人给出当年指南的要求时，以指南为准，并在 `assumptions.md` 记下所用的口径。
- 有科学论证时，各章篇幅以 `section_plan.yaml` 的 `length` 为准。证据不足时篇幅下限只作提示：不用推测或泛泛的背景凑字（规则 6），字数不足的原因写进收尾报告。

## 检查

```bash
python3 S/scripts/length_check.py --input P --out-dir T/nsfc-proposal/output/length [--pdf P/main.pdf]
```

- `--input` 指向项目根目录时，脚本沿 `main.tex` 的 `\input`、`\include` 收集实际编译进 PDF 的文件，忽略被注释掉的 `\input`。
- `--out-dir` 相对当前目录解析。报告写在 `length_report.md` 与 `length_report.json`，不写进项目目录。
- 有 PDF 时一并传入，报告给出页数。

运行后读 `length_report.md`，必要时读 JSON 中的 `sections`（章节级统计）。

## 找差距

1. 找出超长或偏短的文件。`delta` 为 `+N` 表示超长，`-N` 表示偏短，`OK` 表示不必为预算改动。按 `|delta|` 从大到小处理。
2. 文件内看章节级统计：差距集中在一两个小节时，只改这一两节，结构更稳，原意更容易保住。
3. 判断差距的性质：证据链不足（缺数据、对照、局限）、逻辑跳跃（缺过渡、定义、假设）、冗余重复（需要合并、删减）。

## 改写

### 不改变原意的底线

- 不新增原文不支持的结论或主张；有科学论证时，规则 1–9 照常适用，新句子同样要有证据或写占位。
- 不改变因果方向、比较对象、时间范围、研究对象与人群。
- 不改变关键术语的定义；补定义时与原意一致。
- 引用、标签、图表与 LaTeX 结构原样保留。

### 偏短时扩写

先补可验证的信息，再补论证闭环，不堆形容词：

1. 定义与边界：关键概念、研究对象、适用范围、排除条件。
2. 证据链：已有结果的指标、对照、统计口径、局限。
3. 方法可复现性：关键参数、数据来源、质量控制、失败判据。
4. 验证闭环：预期结果怎样验证，备选方案与风险应对。

### 偏长时压缩

1. 去重复：同一论点只留最强的一次表达。
2. 去泛背景：与本项目无关或教科书式的段落压成一两句。
3. 结构化：长段改成三到五个要点句，保持事实顺序。
4. 统一术语：用同一个词替换反复出现的近义词。

### 各章的增删方向

| 章节 | 该瘦 | 该厚 |
|---|---|---|
| 立项依据 | 教科书式科普、泛化综述、弱相关的需求铺陈、重复的意义、凑数的文献 | 缺口 → 切入点 → 价值论证 |
| 研究内容 | 重复表述、过细的操作细节、罗列式方法堆砌 | 逻辑框架、关键设计与对照、预期结果与可验证指标、图 |
| 研究基础 | 无关成果堆砌、过度铺垫 | 强相关的预实验数据、核心技术能力、与研究内容对位的平台条件 |

## 复检

改完再运行一次 `length_check.py`，确认达标且不超标；改写未复检视为未完成。同时复查：每个「因此」「从而」前都有可追溯的前提；指标、对照、结论都还在。

- 不缩小字体、不缩小行距来挤页数。
- 不顶格写到上限，留出余量。
- 改动了已写好的章节时，重新运行该章的 `chapter_check.py` 与 `consistency_check.py`；有科学论证时再运行 `case.py mark-written`。
